# Agent Instructions

## Git & remotes

- **Never merge, push, or open pull requests into the official upstream `mindcraft-bots/mindcraft` repository.** That is the `origin` remote and we treat it as read-only.
- **Always work on our own personal fork** (`davidbegin/mindcraft`, the `fork` remote). All commits, branches, merges, and pushes go there.
- When asked to "push" or "merge" without a named target, assume our personal fork, not upstream.
