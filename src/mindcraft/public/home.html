How it works

the short version — full architecture

One server owns everything

MindServer is an Express + Socket.IO process on localhost:8080. It serves these pages, spawns bot processes, and holds every coordinator. Browser and bots only ever talk to it.

Each bot is its own process

A bot is a Node child process running a Mineflayer client. It keeps its own history, prompts its own model, and is restarted automatically if it dies badly.

The model drives through commands

World state goes into a prompt; the reply comes back with !command(args) calls that the executor runs as skills. Reactive survival modes tick every 300 ms and can interrupt.

Coordinators set the goal

On top of the bots sit three drivers: contests for short judged games, a Survivor season with alliances and votes, and the colony's persistent task board.

The world is controlled over RCON

Bots connect to a Java Minecraft server over the game protocol, while MindServer rebuilds arenas, teleports players, and reads scoreboards through RCON.

Everything is recorded

Per-bot POV video, private conversation transcripts, and every prompt and response are written to disk so a finished run can be replayed and audited.
